Composables (Singletons)

useFilters.js
Global filter state. Refs declared at module scope — all views share the same instance. Exposes getCurrentFilters() which maps UI state to API query params.
singleton shared across all views
useAuth.js
Mock authenticated user. Profile fields (name, job title, tasks) are locale-aware — switches between English and Japanese content based on useI18n.
mock only locale-aware
useI18n.js
Internationalization singleton. Supports en and ja locales. Locale persisted to localStorage. Currency automatically follows locale (USD / JPY).
singleton en / ja localStorage

Key Constraints & Rules

✕ Inventory endpoints do not support month filtering — inventory has no time dimension
! Data changes (POST/PATCH/DELETE) are in-memory only — a server restart reloads original JSON files
! Always validate dates before calling .getMonth() — check !isNaN(date.getTime())
! Use unique keys in v-for — use sku, id, or month, never array index
→ When changing JSON structure in server/data/, update the corresponding Pydantic model in server/main.py
→ Revenue goals: $800K/month (single warehouse) · $9.6M YTD (all months)
○ Charts are custom SVG + CSS Grid — no third-party charting library
○ No emojis in UI · Color palette: slate/gray #0f172a #64748b #e2e8f0
